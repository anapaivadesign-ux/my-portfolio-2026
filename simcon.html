SIMCON

Redesigning a platform with a scalable design system, component library, and SVG animations to enhance usability and team collaboration.

UI/UX Design Design System Figma SVG Animation
01 — Implementation

Building the system

Worked closely with the team to create high-fidelity UI screens in Figma, adhering to Simcon's brand guidelines and design system standards. Focused on clear hierarchy, simplicity, and consistent styling across components. Updated and maintained the component library, and designed SVG animations to subtly enhance user interactions while maintaining usability.

02 — Results

A system ready to scale

The redesigned platform now features a scalable, well-organized design system and component library that streamlines development and design collaboration at Simcon. Interactive SVG animations improved user engagement and enhanced the overall experience. The system is ready for deployment and continuous updates based on team and user feedback.

03 — Learnings

Teamwork makes systems work

This project reinforced the importance of teamwork in maintaining a consistent, usable, and interactive design system. Supporting the component library and introducing SVG animations highlighted how small details create meaningful improvements in both the design process and the end-user experience.
